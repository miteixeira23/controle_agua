## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade do curso técnico em **Desenvolvimento de Sistemas da ETEC**.

O objetivo é criar um sistema simples de monitoramento de um reservatório de água, utilizando Python para identificar diferentes níveis de água e apresentar mensagens de alerta com cores específicas no terminal.

A proposta simula uma situação que poderia ser encontrada em um ambiente real de monitoramento.

## 🎯 Objetivos da atividade

- Utilizar listas para armazenar os níveis do reservatório;
- Aplicar funções para organizar o código;
- Utilizar estruturas condicionais (`if`, `elif` e `else`);
- Conhecer e utilizar a biblioteca Colorama;
- Exibir mensagens coloridas no terminal.

## 🚦 Níveis de monitoramento

| Nível | Situação | Cor |
|:---:|---|---|
| 1 | 🔴 Muito baixo (Crítico) | Vermelho |
| 2 | 🟡 Baixo | Amarelo |
| 3 | 🟢 Médio | Verde |
| 4 | 🔵 Alto | Ciano |
| 5 | 🔵 Muito alto (Alerta) | Azul |

## 🛠️ Tecnologias utilizadas

- 🐍 **Python:** linguagem utilizada para desenvolver o sistema.
- 🎨 **Colorama:** biblioteca utilizada para colorir as mensagens exibidas no terminal.
- 💻 **VS Code:** editor utilizado para escrever e executar o código.

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

É necessário ter o Python instalado na máquina.

### 2. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/controle-niveis-agua.git
```

### 3. Acesse a pasta do projeto

```bash
cd controle-niveis-agua
```

### 4. Instale a biblioteca Colorama

```bash
pip install -r requirements.txt
```

### 5. Execute o programa

```bash
python controle_agua.py
```
